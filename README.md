# Student Performance Prediction Using Machine Learning

## Project Description

This project uses Machine Learning to predict a student's final academic performance based on student-related information.

## Objective

The main objective is to predict the student's final grade and determine whether the student is likely to Pass or Fail.

## Dataset

The project uses the Student Performance dataset (`student-por.csv`).

The dataset contains academic, demographic, and social information about students.

## Machine Learning Algorithm

Random Forest Regression

## Input Features

- Age
- Study Time
- Previous Failures
- Absences
- First Period Grade (G1)
- Second Period Grade (G2)
- Other student-related features

## Target

The target variable is:

- G3 – Final Grade

## Prediction

The system predicts:

- Final Grade
- Pass / Fail
- Performance Level

Performance levels:

- Poor
- Average
- Good
- Excellent
